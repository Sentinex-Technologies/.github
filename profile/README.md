### 📋 Problem Statement Details

**Title:** Social Media Analytics Platform

**Description:**  
Develop a comprehensive social media analytics platform for NTRO that provides:
- Multi-platform data collection and monitoring

- Network topology analysis and opinion leader identification
- Information propagation tracking

- ✅ RESTful API with OpenAPI documentation

## 🚀 OUR SOLUTION: SENTINEX SOCIAL INTELLIGENCE

### 📊 Project Overview

**Sentinex Social Intelligence** is an AI-powered social media analytics platform that fulfills all NTRO requirements with industry-grade implementations.

🔗 **Repository:** [sentinex-social-intelligence](https://github.com/Sentinex-Technologies/sentinex-social-intelligence)

### ⭐ Key Features

#### 🔷 Component A: Multi-Platform Data Collection
- 6 platforms: Twitter/X, Instagram, Facebook, Reddit, Telegram, YouTube
- Real-time ingestion with ISO 8601 timestamping
- Modular connector architecture
- Timeline tracking and historical data storage

#### 🔷 Component B: Multi-Dimensional Sentiment Analysis
- VADER sentiment analysis (compound scoring)
- TextBlob polarity detection
- 5 emotion types: Joy, Anger, Fear, Sadness, Surprise
- 5 sentiment categories with weighted scoring
- Context-aware analysis (negation, emphasis, sarcasm)

#### 🔷 Component C: Demographic Profiling
- Age groups, gender, location, occupation analysis
- GDPR compliant with privacy-first design
- Aggregate statistics only (no PII storage)
- Automated anonymization layer

#### 🔷 Component D: Trend Detection
- TF-IDF algorithm for keyword extraction
- Velocity-based classification (VIRAL, EMERGING, RISING, STABLE)
- 7-day rolling window analysis
- Real-time trend monitoring

#### 🔷 Component E: Network Analysis
- PageRank algorithm for influence scoring
- 4 centrality metrics (degree, betweenness, closeness, eigenvector)
- Opinion leader identification (Top 10)
- Network topology visualization

### 🛠️ Technology Stack

**Backend:**
- FastAPI (Python 3.14+)
- SQLAlchemy ORM with SQLite
- VADER Sentiment, TextBlob
- NetworkX for graph analysis
- scikit-learn for TF-IDF

**Frontend:**
- React 18 with Vite
- Redux Toolkit for state management
- Recharts for data visualization
- TailwindCSS for styling
- Axios for API communication

**Analytics & Algorithms:**
- VADER Sentiment Analysis
- TF-IDF (Term Frequency-Inverse Document Frequency)
- PageRank Algorithm (Google's original formula)
- Centrality Metrics (Degree, Betweenness, Closeness, Eigenvector)
